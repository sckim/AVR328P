# 99. Archive

이 폴더는 현행 커리큘럼에서 물러난 자료를 보관하는 곳이다. 학습 순서에 포함되지 않는다.

## 📂 내용
| 항목 | 설명 |
|---|---|
| `Atmega328P.atsln` | 구버전 Microchip Studio 솔루션. 현행 솔루션은 상위 폴더의 `uC_Examples.atsln`이다 |
| `AVR328P.code-workspace` | VS Code 워크스페이스 설정 |
| `AVR328P_Basic.pdsprj` | Proteus 회로 시뮬레이션 프로젝트 |
| `99_Archive` | 구예제 보관 하위 폴더 |

## 📌 참고
*   여기 있는 파일의 경로 참조는 폴더 재구성 이전 기준이므로 그대로 열면 맞지 않을 수 있다.
