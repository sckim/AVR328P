# 600_DS18B20

1-Wire 프로토콜을 레지스터 수준에서 직접 구현하여 DS18B20 온도센서를 읽는 예제이다. 라이브러리를 쓰지 않는다.

## 🔌 배선
| DS18B20 | 연결 |
|---|---|
| VDD | 5 V |
| GND | GND |
| DQ | PD2, 그리고 DQ–5 V 사이에 **4.7 kΩ 풀업 저항** |

UART 출력은 PD1(TX), 9600 bps 8N1이다.

## 📄 파일
| 파일 | 내용 |
|---|---|
| `onewire.h` / `onewire.c` | Reset·Presence, 비트/바이트 송수신, CRC-8 |
| `main.c` | DS18B20 명령 시퀀스, 분해능 설정, 1초 주기 측정과 UART 출력 |
| `platformio.ini` | PlatformIO 빌드 설정 (framework 없음 = bare-metal) |

## ⏱ 타이밍
| 동작 | Low 유지 | 이후 |
|---|---|---|
| Reset | 480 µs | 해제 후 70 µs 시점에 Presence 샘플링, 410 µs 대기 |
| Write 1 | 6 µs | 해제 후 64 µs |
| Write 0 | 60 µs | 해제 후 10 µs |
| Read | 6 µs | 해제 후 9 µs 시점 샘플링, 55 µs 대기 |

## 🧠 핵심 구현 요령
*   **오픈 드레인**: `PORTD`의 해당 비트는 항상 0으로 두고 `DDRD` 비트만 조작한다. 1이면 Low 구동, 0이면 해제되어 풀업이 High로 끌어올린다. 절대 High를 직접 출력하지 않는다 — 다른 디바이스가 Low로 끄는 순간 단락된다.
*   **인터럽트 차단**: 비트 슬롯은 µs 단위이므로 `cli()`로 막고 끝나면 `SREG`를 복원한다.
*   **CRC 검사**: 스크래치패드 9바이트 중 앞 8바이트의 CRC-8이 9번째 바이트와 일치해야 유효한 값이다.
*   **정수 출력**: `printf`에 `%f`를 쓰면 코드가 크게 늘어난다. raw × 625 ÷ 10으로 0.001 ℃ 단위 정수를 만들어 소수점을 직접 찍는다.

## 🔢 온도 변환
DS18B20은 12비트 분해능에서 0.0625 ℃ 단위의 2의 보수 값을 낸다.

```
T(℃) = raw × 0.0625
예) raw = 0x0191 = 401 → 401 × 0.0625 = 25.0625 ℃
```

## 📌 확장 과제
1.  `ow_reset()` 대기 루프에 타임아웃을 넣어 센서 미연결 시 멈추지 않게 한다.
2.  SKIP ROM 대신 SEARCH ROM을 구현하여 한 버스에 여러 센서를 붙인다.
3.  변환 완료를 `_delay_ms()` 고정 대기 대신 버스를 읽어 감지하도록 바꾼다.
4.  측정값을 `10_I2C_Devices`의 텍스트 LCD에 표시한다.
