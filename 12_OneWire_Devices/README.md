# 12. One-Wire Devices

## 🎯 학습 목표
*   단선 양방향 통신 프로토콜을 µs 단위 타이밍으로 직접 구현한다.
*   오픈 드레인 구조 — 핀을 출력 Low로 끌어내리거나 입력(하이 임피던스)으로 놓아 풀업이 끌어올리게 하는 방식을 이해한다.
*   CRC-8로 수신 데이터의 무결성을 검사한다.

## 🛠 주요 부품
*   DS18B20 디지털 온도센서, 4.7 kΩ 풀업 저항 (DHT11/DHT22도 유사한 단선 방식이나 프로토콜은 다르다)

## ⏱ 1-Wire 타이밍 요약
| 동작 | 마스터 동작 |
|---|---|
| Reset | 480 µs 이상 Low → 해제 후 60~240 µs 내 Presence 펄스 확인 |
| Write 1 | 1~15 µs Low → 해제, 총 60 µs 이상 유지 |
| Write 0 | 60~120 µs Low → 해제 |
| Read | 1~15 µs Low → 해제 후 15 µs 이내에 샘플링 |

## 📂 예제
| 폴더 | 내용 |
|---|---|
| `600_DS18B20` | 1-Wire 프로토콜 직접 구현 + DS18B20 온도 측정, UART 출력 |

## 📌 참고
*   타이밍이 핵심이므로 통신 구간은 `cli()` / `sei()`로 인터럽트를 막아야 한다.
*   데이터선에는 반드시 4.7 kΩ 풀업 저항이 필요하다.
*   `DDRx` 비트를 0으로 두고 `PORTx` 비트도 0으로 유지한 채, `DDRx`만 조작하여 Low 구동과 해제를 전환하는 것이 오픈 드레인 구현의 요령이다.
